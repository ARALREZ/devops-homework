# DevOps Lab 2

## Cel
Ćwiczenie podstaw Git i GitHub w pracy zespołowej.

## Wykorzystane narzędzia
- Git
- GitHub
- Terminal

## Instrukcja pracy
1. Utworzenie repozytorium.
2. Utworzenie gałęzi roboczej.
3. Wprowadzenie zmian w README.md.
4. Zapisanie zmian w commicie.
5. Wysłanie gałęzi na GitHub.
6. Utworzenie Pull Requesta.
7. Code review i merge.
