# Mój plan DevOps

## Czym jest DevOps?
DevOps to kultura i zbiór praktyk łączących development (tworzenie oprogramowania) 
z operations (utrzymaniem i wdrażaniem). Celem jest szybsze, bardziej niezawodne 
dostarczanie oprogramowania poprzez automatyzację, CI/CD, monitoring i współpracę zespołów.

## Co chcę osiągnąć w tym kursie?
- Nauczyć się podstaw Git, Docker i CI/CD
- Potrafić samodzielnie konfigurować środowiska deweloperskie
- Zrozumieć praktyki Infrastructure as Code
- Przygotować się do pracy z narzędziami DevOps w praktyce
