# Mój Plan DevOps

## Czym jest DevOps?
DevOps to połączenie rozwoju oprogramowania (Development) i zarządzania infrastrukturą (Operations), którego celem jest automatyzacja, ciągłe dostarczanie (CI/CD) i szybkie wdrażanie wysokiej jakości oprogramowania.

## Cel w tym kursie:
- Opanowanie konteneryzacji aplikacji za pomocą Dockera.
- Nauki automatyzacji procesów i koncepcji Infrastructure as Code (Terraform).
- Skonfigurowanie profesjonalnego środowiska do codziennej pracy z projektami.
